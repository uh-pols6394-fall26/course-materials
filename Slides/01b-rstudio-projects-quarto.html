What Quarto Makes

One Source, Several Outputs

You write one plain-text .qmd file. Quarto turns it into the format you need.

analysis.qmd
    ├── HTML report or web page
    ├── PDF or Word paper
    ├── revealjs presentation
    ├── website or dashboard
    └── book

The writing and the computation stay together in the source.

A .qmd Can Become a Paper

Same source: Markdown for the writing, R for the figure, and Quarto for the finished paper.

The example is Slides/Demos/paper/paper-example.qmd.

Quarto and R Markdown

  • R Markdown uses .Rmd files. It established the modern workflow for mixing R, prose, tables, and figures, and remains common in replication archives.
  • Quarto uses .qmd files. It keeps that workflow while providing one system for papers, presentations, websites, dashboards, and books.
  • Quarto works with R and Python, and does not require code when a document contains only prose.
  • Cross-references, citations, layouts, and revealjs slides are built into Quarto rather than assembled from separate R Markdown packages.
  • Both use YAML, Markdown, and code chunks, so skills learned in one transfer readily to the other.

Use Quarto for new work. Expect to encounter R Markdown in existing projects.

Your First Paper

Why Use PDF?

What PDF does well

  • Keeps the same page layout on different computers
  • Normally embeds fonts and preserves figure placement
  • Works well for printing and archiving
  • Common for papers sent to journals and committees

What PDF does poorly

  • Fixed pages are awkward on phones and small screens
  • Text does not reflow when a reader changes the window or font size
  • After a revision, you must render and send a new copy

LaTeX and Typst Make the Same Kind of File

  • PDF (LaTeX) is the established academic route, with broad support for journal templates. It needs a TeX installation.
  • PDF (Typst) is faster and comes with Quarto. It is newer and has fewer publisher-specific templates.

Posit Cloud has both. We will use Typst for the first paper.

What RStudio Gives You

The starter has all three parts of a Quarto document:

---
title: "My First Paper"
author: "Your Name"
format: typst
---
  • YAML is the block between the --- lines. It gives Quarto the document’s title, author, and output format.
  • Sample Markdown text
  • A sample R code chunk
  • A document that should render before you change anything

Read the Source

Three Parts of a .qmd

  • YAML sits between the --- lines and controls the title, author, and output format.
  • Markdown is the prose and document structure.
  • Code chunks run R and place results in the rendered document.

The source stays readable even before you render it.

Headings, Paragraphs, and Emphasis

## A Section Heading

This is a paragraph with **bold text** and *italic text*.

This is a second paragraph. `first-paper.qmd` is a file name.
  • One # makes a large heading; more # characters make lower-level headings.
  • Leave a blank line between paragraphs.
  • Use backticks for file names, commands, and short pieces of code.

Lists, Links, and Footnotes

- one bulleted item
- another bulleted item

1. first numbered item
2. second numbered item

[Quarto documentation](https://quarto.org/docs/guide/)

This sentence has a footnote.^[The note appears at the bottom of the page.]

A labeled link is easier to read than a long URL. Quarto numbers footnotes when it renders.

Code Chunks Put R in the Document

A chunk begins with ```{r} and ends with ```.

numbers <- c(4, 8, 15, 16, 23, 42)
mean(numbers)
[1] 18

<- assigns a value to an object. c() collects several values into one vector. mean() takes that vector and returns one number.

Use the green triangle to run one chunk. Rendering runs every chunk in order.

Rendering Builds the Whole Document

Clicking Render:

  1. starts a fresh R session;
  2. runs the chunks from top to bottom;
  3. combines the Markdown, results, and formatting; and
  4. writes the finished output.

When rendering stops, the error tells you which chunk to inspect first.

The Console Can Render It Too

In the Console pane, run:

quarto::quarto_render("first-paper.qmd")

The Render button and the R command both build the document from the saved source. Later we will use this command to render several documents automatically.

Render the Paper to HTML and PDF

Give the paper two formats in YAML:

format:
  html: default
  typst: default

Use the Render button’s menu to choose a format, or run quarto::quarto_render("first-paper.qmd") in the Console to build both. Typst produces the PDF.

Put It on the Web

A Web Page Needs a Host

Rendering creates an HTML file in your project. Other people cannot reach a file that exists only inside your project.

first-paper.html  →  web host  →  public URL  →  reader's browser

A host stores the rendered files on an internet-connected server and sends them to anyone who visits the URL.

Today we will use Posit Connect Cloud. Later we will use GitHub Pages to host work connected to a GitHub repository.

Give the Page a Recognizable Address

The default address uses a generated content ID:

https://[content-id].share.connect.posit.cloud

After publishing, open the content page and choose Edit Settings → URL → Custom name. A short name such as first-paper produces an address like:

https://[account-name]-first-paper.share.connect.posit.cloud

It remains a Connect Cloud address, but it is easier to recognize and share.

If Time Remains

Source Mode and Visual Mode

RStudio can edit the same .qmd in two ways:

  • Source mode shows the Markdown and code exactly as written.
  • Visual mode gives the prose a word-processor-like view.

We’ll use source mode while learning the structure. You can switch modes without creating a second file.

A Few Useful Chunk Options

Options are #| lines at the top of a chunk.

#| echo: false
  • echo: false runs the code but hides it in the output.
  • eval: false shows the code without running it.

Leave both alone today unless we have extra time to compare them.

A Self-Contained HTML File

Normal HTML output may depend on a neighboring _files/ folder. Add this YAML when you need one file that can be emailed or archived:

format:
  html:
    embed-resources: true

The HTML file becomes larger because Quarto puts its images, styles, and scripts inside it.
